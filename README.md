# Pico-Frame-Work
A beginner-friendly embedded framework for Raspberry Pi Pico (RP2040) using C/C++ SDK. Includes GPIO control, UART, PWM, ADC reading, and a modular code structure to help beginners quickly build and expand embedded projects.
A simple and modular embedded framework for Raspberry Pi Pico using the RP2040 C/C++ SDK.
This project is designed to help beginners understand:

Basic GPIO input/output

LED blinking

Button interfacing

ADC (Analog Sensor Reading)

PWM control (LED dimming / motor speed)

UART communication

Clean folder structure for scaling projects
